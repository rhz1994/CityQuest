## Goal

Create a simple interface for managing CityQuest content.

## Why is this useful?

Content creation should not require direct database editing or manual API calls.

## Proposed solution

Build a small admin UI for cities, locations, quests, clues, and puzzles.

## Acceptance criteria

- [ ] Admin can view existing cities and quests.
- [ ] Admin can create or edit content.
- [ ] Non-admin users cannot access admin tools.
- [ ] Admin workflow is documented.
