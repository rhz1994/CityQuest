## Goal

Create one complete playable quest for a real city.

## Why is this useful?

The app needs at least one polished quest to test the full experience: location
permissions, maps, clues, physical distance checks, puzzle solving, progress,
and completion rewards.

## Proposed solution

Pick one city, define a short quest route, write clues and puzzle answers, add
coordinates, and test the route on a physical device.

## Acceptance criteria

- [ ] One city is selected for the first real test quest.
- [ ] Quest has a clear name and short description.
- [ ] Quest has at least 3 locations.
- [ ] Each location has a clue and puzzle.
- [ ] Coordinates are verified in the real world or on-site test plan.
- [ ] Quest can be completed end-to-end in the mobile app.
