# CityQuest Issue Drafts

These are draft GitHub issues for the first structured CityQuest backlog.

GitHub will not automatically create issues from these files when you push the
repo. Use them in one of two ways:

1. Copy each draft into GitHub Issues manually.
2. Use `scripts/create-github-issues.mjs` with a GitHub token to create them via
   the GitHub API.
