## Goal

Let users save quests they want to play later.

## Why is this useful?

The Account screen already has a saved quests section, but it is currently only
a placeholder.

## Proposed solution

Add a `savedQuests` table, API endpoints, and mobile UI controls.

## Acceptance criteria

- [ ] User can save a quest.
- [ ] User can unsave a quest.
- [ ] Account screen lists saved quests.
- [ ] Saved quests are private to the current user.
